========================
RESTCONF Device Commands
========================

This section shows the JSON payloads generated by each RESTCONF device driver
for each supported operation. The JSON is rendered with example values
(VLAN 100, port Ethernet1/1) to illustrate the OpenConfig structure sent
to the switch via RESTCONF ``PATCH`` requests (RFC 8040 / RFC 7951).

Each payload is shown alongside the RESTCONF resource URL it targets.
The driver sends one ``PATCH`` per top-level YANG container.
